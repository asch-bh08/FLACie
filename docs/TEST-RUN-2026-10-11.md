no private names/addresses/keys in any tracked file.

## Checklist

### Basics
- [ ] Home scrolls smoothly (nothing stuck or clipped), nav, back stack, pull to refresh
- [ ] Orientation changes, dark and light mode, max font and display scaling, split-screen
### Library
- [ ] Artists, albums, songs, folders, search, Explore with the quality filter, charts
### Player
- [ ] Play/pause/seek (thumb clipping at both ends, scrub accuracy)
- [ ] Next/previous, **old skip freeze gone** (skip 20 songs quickly; the page/app must stay alive)
- [ ] Shuffle, repeat, queue (add, reorder, remove, play next), gapless
- [ ] Full-screen player and its menu, lyrics, sleep timer (if present)
- [ ] Info panel: spectrum, chips, real metadata, "Came from", Playback row; hi-res tags
- [ ] Covers: missing, slow, wrong, filename-style titles
### Playlists
- [ ] Create, rename, add (with confirmation and undo), remove, reorder, delete, import, iPod playlist sync (if present)
### Downloads
- [ ] Request songs, per-song status, Downloads page and log, "Streaming" songs before the next Jellyfin scan
- [ ] Notifications: requested, completed, now playing
### Accounts and settings
- [ ] Password and Quick Connect sign-in, sign-out, switching accounts
- [ ] Every Settings field and notification toggle; non-admin vs admin; Admin pages
### Multi-device
- [ ] Jams and Connect between Fold, RG Rotate and web
### Device specific
- [ ] Fold: cutouts, gesture and 3-button nav, current screen size, permission prompt flow
- [ ] RG Rotate: 720x720, rotation, D-pad/button/joystick navigation, touch plus gamepad, low-power performance, tap targets
- [ ] Both: background playback, screen off, lock-screen and notification controls, headphones and Bluetooth buttons, audio focus,
      rotating while playing, kill and restore, offline and poor network, Wi-Fi to mobile switching
### Edge cases
- [ ] Empty library, huge playlists (10,036 songs), very long titles, missing artwork, unicode and emoji, odd metadata
- [ ] MP3 vs FLAC vs hi-res, expired session, server unreachable, slow server
### Performance
- [ ] Startup time, jank (gfxinfo), memory over a 30 minute playback and browse loop on the Fold (does the 243 MB resident figure keep growing?)
### Windows MSI (D)
- [ ] Install, launch, sign in, play, upgrade over the previous version, uninstall, leftover files / services / registry
### Server and API (E)
- [ ] Every endpoint: auth required, bad input, error handling, rate limits; Downloads log; notifications and ntfy (401/403 wording, token never logged)
- [ ] Jellyfin 10.10.x and 12.x

## Audio checks the owner must do by ear (nothing here can be heard by the test agents)
- [ ] Headphone test: left/right, tone generator, bass, sweep (Android and web)
- [ ] Gapless transitions (an album that is meant to run through)
- [ ] Lossless playback: FLAC, hi-res, Apple Lossless (served as WAV by the server)
- [ ] Volume level / limiter sanity on the headphone test
