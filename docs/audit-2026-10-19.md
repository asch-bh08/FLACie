# FLACie audit, 2026-10-19 (beta 71, main b9e1225)

Written as it goes. Each line: area, what was checked, result.

## Dependencies and secrets
- NuGet known-vulnerable packages (incl. transitive), Server/Core/App/Retro/RetroWasm/Hybrid: none.
- Tracked key/cert/.env files in git: none. Hard-coded long keys/passwords in source: none found.

## Web server (FLACie.Server)
- Endpoints: every data endpoint either has RequireAuthorization or checks the session itself (Who()); /api/settings POST and /api/admin/load also check admin. OK.
- Cookie SameSite=Lax, so the antiforgery-off POSTs (/auth/logout, /api/*) can't be triggered from another site with the cookie. OK.
- Login has a throttle (per IP and per user). OK. Quick Connect poll (/auth/qc/poll) has no throttle, but it needs the secret from /start, which does. Low.
- MEDIUM, only if FLACIE_JELLYFIN_URL is not set: /auth/jellyfin and /auth/qc/start take the server address from the form, so anyone can make the server send requests to any address (including LAN ones). With the variable set (server fixed), this is closed. Check frank sets it; the docs should say to set it on public servers.
- LOW: /debug/library and /debug/jf have no loopback check (unlike /debug/login and /debug/token). They only work when FLACIE_DEBUG=1 and only for the signed-in user's own account, but the startup warning says "loopback only", which isn't true for these two.
- /art/{key} rejects '/', '\' and '..' in keys. OK.

## Android app (com.ipodemu, beta 71)
- Retro WebView: file and content access off, loads only its own asset host (other hosts are refused), DevTools only in debug builds. OK.
- Retro bridge (FLACieAndroid.call): a short fixed list (library, state, load, play/pause/seek, volume, speed, facts, frame, close); bad input is caught and logged. OK.
- ArtProvider is exported (needed so Android Auto can show covers): read-only and blocks '/', '\' and '..' in keys. Any app on the phone can read cover pictures by key. Low, by design.
- LOW: usesCleartextTraffic="true" for the whole app. Needed for http:// Jellyfin on a home network, but a network security config allowing cleartext only for private addresses would be tighter.
- MANAGE_EXTERNAL_STORAGE is requested (Play Store would question it; fine for GitHub releases).

## Windows app (MSI 0.71.0)
- The bundled server listens on 127.0.0.1 only, its data lives in %LOCALAPPDATA%\FLACie\web, and it stops when the app closes. OK.
- LOW: the bundled server takes on the app's whole environment, so a FLACIE_DEBUG=1 set on the PC would switch the /debug endpoints on. Clearing it in FlacieHost would close that.
- LOW: the Jellyfin address is typed by the person (no fixed server). That's right for a desktop app, and only reachable from this PC.
