## Pitfalls hit this session
- PowerShell pipes corrupt binary data: for `tar | ssh` write a file and `scp` it; for screenshots use `adb shell screencap` + `adb pull`.
- `Start-Sleep` of long durations is blocked by the harness; use background commands/Monitor.
- Foreground `ssh` with quotes inside PowerShell breaks: write a .sh file, `scp` it, run it.
- Parallel Gradle/dotnet publish builds exhaust RAM: use a lock file around heavy builds (`C:\FLACie_build.lock`, exclusive open).
- Browser tests need Node (installed via winget; refresh `$env:Path` from the registry in new shells).
- `adb` wireless: the pairing port and the connect port differ and both change; mDNS may show a stale address; pair with the code, then connect to the port shown on the phone's main Wireless debugging screen.
- RG Rotate: never enable cutout overlays; swipes above the mini-player strip (y < 580); media button/gamepad key codes via `input keyevent`.
