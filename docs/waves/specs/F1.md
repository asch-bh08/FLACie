# F1 Never a blank cover

## Summary

Every song shows a cover. Covers are tried in order: Jellyfin, the song's own release, the album, the folder picture, the artist photo, then a generated cover (artist and title on the app's colours). Songs with no artist tag (137, e.g. Eminem/Singles/Eminem_Lose_Yourself.mp3.mp3) take the artist from the file or folder name. A background pass on frank fetches and saves every cover and row tile once, paced for the catalog's limits.

## In scope

- The fallback chain and the generated cover
- Artist from file/folder names on the server
- Background fill pass with progress in Server admin

## Out of scope

- Writing tags back into the music files
- Choosing covers by hand (exists)
