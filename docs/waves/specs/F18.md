# F18 Synced lyrics for most songs

## Summary

Lyrics come only from LRCLIB, so many songs have plain lyrics or none. Add NetEase as a second source after LRCLIB (no key), with a length
tolerance so radio edits and album versions still match. Then, in testing only, time plain lyrics on frank by aligning them to the audio with a
small speech model, one song at a time overnight under a memory limit (frank ran out of memory on speech tests before), saving each result for good.

## In scope

- NetEase synced lyrics after LRCLIB; length tolerance
- Overnight alignment of plain lyrics on frank, behind a setting, off by default

## Out of scope

- Paid lyric services
- Aligning on the phone

## Acceptance criteria

```yaml criteria
AC1: {text: "A song LRCLIB has only plain lyrics for gets NetEase's synced lyrics when NetEase has them", verify: "test:ipodsync/tests/FLACie.Tests/LyricsNeteaseTests.cs"}

```

## Steps

- F18.1 NetEase source after LRCLIB, with length and artist checks (Cloud).
- F18.2 Overnight alignment job on frank, off by default, tried by Local with a memory limit (Local).
