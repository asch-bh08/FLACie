# F25 Import any playlist link, and a tidy Import page

## Summary

Like Soundiiz / TuneMyMusic, but only from links anyone can open (no sign-in, no borrowed keys). The owner pastes a playlist or album link
from any of these and FLACie makes the playlist, matches songs already in the library and downloads the rest (the normal Import pipeline):

- Spotify, Deezer: already done (Spotify gives its first 100).
- YouTube and YouTube Music playlists: through flacie-ytdl (yt-dlp `--flat-playlist`; titles like "Artist - Song (Official Video)" are cleaned
  into artist + title). Checked by Local on frank 5 Nov: a YouTube Music playlist link lists its songs.
- SoundCloud sets (playlists/albums): through flacie-ytdl (yt-dlp without --flat-playlist; flat gives no titles). Checked: The Prodigy's
  "The Fat of the Land" set gives Smack My Bitch Up / Breathe / Diesel Power with uploader The Prodigy.
- Apple Music playlists and albums: the public page (music.apple.com/...); song names and durations are in its
  `<script type="application/ld+json">` (MusicPlaylist.track[]); artist names are in `<script id="serialized-server-data">`. Checked: Today's
  Hits gives 50 songs. Real page saved by Local: ipodsync/tests/FLACie.Tests/TestAudio/apple/todays-hits-real.html (50 songs, first "Solar Eclipse" by Drake).
- Anything else: "FLACie can't read that link yet" with the list of what it can.

flacie-ytdl gets a new endpoint `/playlist?url=` (allowed hosts only: youtube.com, music.youtube.com, youtu.be, soundcloud.com), at most 500
entries, answering [{title, artist, durationMs}]; Local redeploys it.

F25.2 the Import page (owner, 5 Nov: "this page is ugly"): the explanations are set in the monospace font and run off the right edge of the
card; the page scrolls sideways at desktop width and the side menu is cut off; the "Replace playlists with the same name" box has no visible
switch; old finished imports (TEST-A-import.txt from 11 Oct) sit there for ever. Make it look like the rest of the new look (Home / Search):
one paste box first ("Paste a playlist link from Spotify, Apple Music, YouTube, SoundCloud or Deezer") with the service's icon appearing as
it is recognised, the file drop second as a smaller drop zone, the Replace option a real toggle, readable body font, wraps at every width
(phone 375 px included), and past imports listed compactly (name, source icon, "32 of 40 added", date) with finished ones older than 7 days
folded under "Older".

F25.3 SoundCloud artists' own playlists, found quietly (owner, 5 Nov: "do that for the playlists quietly in the background and convert it the
same way our Spotify playlists do"). No key, only yt-dlp in flacie-ytdl, checked by Local on frank:
1. `yt-dlp --flat-playlist --print "%(uploader)s|%(uploader_url)s" "scsearch5:<artist>"` gives the artist's official account (take the
   uploader whose name is exactly the artist, same rule as SpotifyPlaylists.IsEditorsBestOf; none = no SoundCloud lists). Remember it 7 days.
2. `yt-dlp --flat-playlist <account>/sets` lists the account's sets (names + links, cheap): for The Prodigy "The Fat Of The Land 25th
   Anniversary - Remixes", "Experience: Expanded (Remixes & B-sides)", "PAY CLOSE ATTENTION: XL Recordings", singles with remixes, albums.
3. They become WebPlaylists source "soundcloud" (kind Artist) through the same store, gate (1 a second per source, 6 h rest after an error),
   search ranking, Playlists filter and download-as-interest-shows policy as F23. Songs are read (F25.1's /playlist) only when a list is opened
   or played. Same name twice shows once; a set whose name is an album already in the library is not shown; one list per purpose still holds
   (Spotify > Deezer > SoundCloud > our own) - remix and B-side sets count as their own purpose ("<artist> remixes"), so they show beside the
   best-of.
flacie-ytdl gets `/artist-sets?q=<artist>` doing steps 1-2 (answer {account, sets:[{title,url}]}, at most 50 sets).
