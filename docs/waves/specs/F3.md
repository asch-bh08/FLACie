# F3 Library copy on the phone

## Summary

The phone keeps the library list and small cover tiles (tens of MB) so Home, Search and playlists open instantly, then refresh in the background. No songs are cached (Offline downloads is for that).

## In scope

- Saved library list opens before any network
- Row tiles kept on disk with a size cap

## Out of scope

- Caching songs
