# F7 Remixes and SoundCloud

## Summary

SoundCloud joins the download source race through yt-dlp (no API key). Remix-aware search on YouTube and SoundCloud keeps the remix name, checks uploader and length, and never swaps in the original. Ranking: lossless > SoundCloud original file (the producer's free download) > YouTube ~160k Opus > SoundCloud 128k. The quickest plays first; anything lossy is queued for the lossless upgrade.

## In scope

- SoundCloud source via scsearch, original-file download when offered
- Remix matching

## Out of scope

- SoundCloud Go+ accounts
