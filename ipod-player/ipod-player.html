JAILBROKEN iPod TOUCH — EXPERIMENTAL

Connect over Wi-Fi

Stream directly from a jailbroken iPod Touch running a web server, over your local Wi-Fi. No cable needed.
Setting up a jailbroken iPod Touch for Wi-Fi

An iPod Touch runs iOS, so it can't be read as a USB drive from a browser. The jailbreak lets you run a small web server on it that this player connects to.

  1. On the iPod, open Cydia and install a web/file server that serves the filesystem — e.g. Apache, lighttpd, or a WebDAV/HTTP file-manager package. Point its document root at /var/mobile/Media (or the filesystem root).
  2. Enable CORS on that server (send Access-Control-Allow-Origin: *). Reading the library database requires it. Tip: the most reliable setup is to place this ipod-player.html file into the server's web root and open it from the iPod's own address — then no CORS is needed at all.
  3. Find the iPod's Wi-Fi IP: Settings › Wi-Fi › (i).
  4. Enter http://<that-ip>:<port> above and Connect. The player looks for iTunes_Control/iTunes/iTunesCDB under that address.

Alternative (no Wi-Fi): with the jailbreak, copy the whole iTunes_Control folder off the device with iFunbox / iExplorer / Filza, then use Open a folder instead — fully reliable.

Playback needs MP3 or AAC/M4A (what iPods normally hold). ALAC/AIFF may not play in the browser. Album artwork isn't shown — tiles are generated from each album's name.

Part of asch-bh08/ipodsync — an open-source iPod manager
